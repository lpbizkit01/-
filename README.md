# 🏟️ 클래스룸 퀴즈 아레나

학생들이 모바일 기기로 접속해서 캐릭터를 움직이며 함께 퀴즈를 푸는 수업용 실시간 게임 플랫폼입니다.

## 주요 기능

| 기능 | 설명 |
|---|---|
| 문제 관리 | 관리자(선생님)가 OX / 객관식 / 주관식 문제를 작성·수정·삭제하면 파일(`data/questions.json`)에 영구 저장 |
| 학생 입장 | 고정 주소로 접속 → 닉네임, 색깔, 꾸미기(모자·리본·왕관·안경·꽃) 선택 후 입장 |
| 걸어서 이동 | 터치(클릭)한 지점으로 캐릭터가 **순간이동 없이 걸어서** 이동 (걷기 애니메이션 포함) |
| OX / 객관식 | 화면에 구역이 나타나고, 제한 시간 안에 정답 구역으로 이동해서 답 선택 |
| 주관식 | 각자 답을 비밀로 입력 → 시간 종료 후 모두 공개(말풍선) → 선생님이 정답/오답 판정 |
| 하트(체력) | 학생마다 하트가 있고 오답이면 1개 감소, 모두 잃으면 탈락(유령) — 하트 개수는 게임 시작 전 설정에서 변경 가능 |

## 실행 방법

```bash
npm install
npm start
```

- 학생 접속: `http://<서버주소>:3000`
- 관리자 접속: `http://<서버주소>:3000/admin` (기본 PIN: `1234`)

환경 변수:

- `PORT` — 포트 번호 (기본 3000)
- `ADMIN_PIN` — 관리자 PIN (기본 1234)

같은 교실 Wi-Fi에서 쓰려면 선생님 컴퓨터의 IP 주소(예: `http://192.168.0.10:3000`)를 학생들에게 알려주면 됩니다. 관리자 화면 오른쪽의 큰 아레나 화면을 프로젝터/TV로 공유하며 진행하세요.

## 수업 진행 흐름

1. **문제 준비**: `/admin` → 「문제 관리」에서 문제 작성 후 저장
2. **하트 설정**: 「게임 설정」에서 하트 개수 지정 (대기 중일 때 즉시 반영)
3. **학생 입장**: 학생들이 접속해 캐릭터를 꾸미고 입장 (대기 중엔 자유 이동)
4. **문제 시작**: 출제할 문제 선택 → 「▶ 문제 시작」
   - OX/객관식: 학생들이 구역으로 이동, 시간 종료 시 서 있는 구역으로 자동 채점
   - 주관식: 학생들이 비밀 입력 → 종료 후 답 공개 → 판정 패널에서 ⭕/❌ 지정 → 「판정 적용」
5. 오답 학생은 하트 -1, 하트가 0이 되면 **탈락**(유령 모드로 구경)
6. 「전체 초기화」로 하트를 리셋하고 새 게임 시작

## 기술 구성

- Node.js + Express + Socket.IO (실시간 동기화)
- HTML5 Canvas (아레나·캐릭터 렌더링, 서버 권위 이동 + 클라이언트 보간)
- 별도 DB 없이 JSON 파일에 문제 저장
